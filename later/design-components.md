# Design skill: components to write

Only the common components, and the ones an AI tends to get wrong. Not every shadcn component.
Each: `skills/design/components/<name>.md` (lean, sourced rules) + `<name>.html` (the same, shown).
Several related components share one guide where the real decision is choosing between them.

- [x] General rules (skills/design/general.md + general.html): what every screen follows
- [x] Button
- [x] Typography: headings, body, muted text, lists, code
- [x] Field: input, textarea, label, help text, errors (shadcn Input, Textarea, Label, Field)
- [x] Select: select vs combobox vs radio, native select
- [x] Choice: checkbox vs radio group vs switch
- [x] Card
- [x] Badge
- [x] Alert: banners in the page
- [x] Toast: short notices that go away
- [x] Dialog: dialog and alert dialog (confirm)
- [x] Sheet: side sheet, bottom sheet / drawer on mobile
- [x] Dropdown menu
- [x] Tooltip: tooltip vs popover vs hover card
- [x] Tabs
- [x] Table: table and data table (sort, filter, pagination)
- [x] Sidebar: app navigation
- [x] Date picker: calendar in a popover
