Permissions

Behavior

Model

Voice input

Press Space in an empty input box (or type /voice) and talk: your words show in the box as you speak, and Enter sends them. Esc cancels.

External tools

Some features need a tool on your machine. Ready ones are ticked; the rest say what to install.

Web search

The engines HeartCode searches with, in this order: it asks the first one, and the next only when that one hasn't found enough, fails, or takes over 3 seconds. None needs a key.

Status bar

The line(s) at the bottom of HeartCode. Drag items into each line, or onto the right to push them to the edge. Saved for next time; a running HeartCode updates right away.

Live preview

Lines

Drag an item from the palette into Left or Right. Drag chips to reorder or move between lines; the × removes one.

Items

Drag any of these into a line above. Each one appears once it's placed.

System prompt

What HeartCode tells the model. Change a prompt and save: a running HeartCode uses yours from the next message. {{names}} are filled in by HeartCode; Reset puts HeartCode's back.

MCP servers

Programs that give the model more tools: a browser, a database, your issue tracker. Off: HeartCode doesn't start it or offer it to the model.

Edit mcp.json directly

For what the form doesn't have: environment variables ("env"), headers, and so on.

Skills

Ready-made prompts. You type one as /skill:name, or the model uses it when it fits.

Install from GitHub or a URL

A GitHub repo (owner/repo or its link) or a link to a SKILL.md. Same as /install_skill in HeartCode; installed for every project.

Settings files

The rest of HeartCode's settings, as the files they're kept in (). A JSON file that doesn't parse isn't saved; save one empty to delete it.

Empty: as found (models.dev, the server, or what HeartCode learns). Measure asks the server.
