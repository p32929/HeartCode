Providers & models

A provider is a service with models (OpenRouter, Groq, Ollama on this machine…). Add one, then choose which of its models HeartCode uses.

Add a provider

Pick one to fill in its address, or type any OpenAI-compatible API below.

Kept in config.json on this machine. This page only shows its first and last characters.

Your models

Every model in your list, with what it can do. Click a column to sort by it, then more columns to break ties; click again to flip, a third time to drop it. Save the order you see, or drag a row: that saves the order you see with your change, and you go on from there.

Logging

What HeartCode writes down, for finding out what went wrong. Off unless you switch it on.

The run's log

Everything each run does, as text: requests, replies, retries, tools, commands, what you typed.

Requests

Each request to a model and its reply or error: which failed, which worked, and which fallback answered.

Everything can make big files on long conversations. API keys are never written.

Thinking and context

Features

Switch each one on or off.

Voice input

Ctrl+R in HeartCode. Empty: whisper-cli on this machine. Or a provider's transcription API: { "provider": "groq", "model": "whisper-large-v3" }; add "language": "auto" for other languages.

System prompt

What HeartCode tells the model. Change a prompt and save: a running HeartCode uses yours from the next message. {{names}} are filled in by HeartCode; Reset puts HeartCode's back.

MCP servers

Programs that give the model more tools: a browser, a database, your issue tracker. Off: HeartCode doesn't start it or offer it to the model.

Add a server

The command that starts it on this machine, or the URL of a remote one (a sign-in page opens if it needs one).

Edit mcp.json directly

For what the form doesn't have: environment variables ("env"), headers, and so on.

Skills

Ready-made prompts. You type one as /name, or the model uses it when it fits.

Advanced files

The rest of HeartCode's settings, as the files they're kept in (). A JSON file that doesn't parse isn't saved; save one empty to delete it.
