Dropdown menu

A dropdown menu is a list of actions behind a button: Edit, Duplicate, Delete, or a ⋯ menu for the rare ones. It's for doing things, not for picking a value in a form, and not for a site's main navigation.

Actions, not form values

A value → Select, radios or checkboxes.

Short and grouped

About 5–15 items, most used first.

A verb and its object

One line, sentence case: "Duplicate project".

Works by keyboard

Arrows move; Esc closes and returns focus.

Before you ship

In code: trigger <button aria-haspopup="menu" aria-expanded>; role="menu" with menuitem / menuitemcheckbox / menuitemradio (aria-checked), <hr role="separator">, aria-disabled items still focusable; keys as in the APG Menu Button (arrows, Home/End, a letter jumps, Tab leaves). The list as a popover (popovertarget): top layer, click outside and Esc close it, focus returns; newly available (Baseline 2025), so check Object.hasOwn(HTMLElement.prototype, "popover") and fall back to your script. Position it with a few lines of JS; CSS anchor positioning (Baseline 2026) only as an extra. Basecoat: .dropdown-menu › button › [data-popover] › [role=menu], with its dropdown-menu.js.

  • Only actions; values in forms use a Select, radios or checkboxes
  • Most used first, grouped, about 5–15 items, at most two levels
  • Every item a verb and its object; destructive ones red
  • Opens and works by keyboard; Esc returns focus to the button; ⋯ has an aria-label
