Tabs

Tabs show one of a few related panels in the same place. Choices that only change how the same content is shown are a segmented toggle; broad, unrelated content is separate pages.

1–2 word labels. No second row, no all caps.

Most-used first

And selected when the page opens.

Never disable a tab: remove it, or say why it's empty.

Segmented toggle

One on at a time; nouns, all text or all icons; equal widths, about five at most.

Text

Equal widths, noun labels. Click one.

Icons

All icons: each with an aria-label and a tooltip.

In code
<button aria-pressed="true">Week</button>

Toggle buttons in a role="group"; the label stays the same when pressed.

Before you ship

In code: role="tablist" with an aria-label, role="tab" buttons with aria-selected and aria-controls, role="tabpanel"; arrow keys between tabs, Tab into the panel. Basecoat: .tabs and its tabs.min.js. Other pages: <a href> with aria-current="page".

  • Tabs only for sections people need one at a time
  • One row of 1–2 word labels; the most-used tab first and selected
  • Selected tab clearly marked; no disabled tabs
  • Arrow keys move between tabs; panels and tabs linked with ARIA
  • Links to other pages are <a href>, not tabs
