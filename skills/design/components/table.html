Table

A table lets people compare records across rows and columns. A plain Table for a short list; a Data Table when people sort, filter, page or act on many rows. Never for page layout.

First column names the row

A readable name, not an auto-generated ID.

Numbers right-aligned

Header and cells alike; text left.

Row actions

One or two inline, more in a ⋯ menu; many rows by checkbox.

Empty state, and phones

"No results." and still readable at 390 px.

Before you ship

In code: a real <table> with <caption>, <th scope="col"> (and scope="row"); a sortable header is a <button> in the <th>, aria-sort on the sorted one only. Basecoat: .table-container around table.table, data-state="selected" on a row.

  • First column names the row; columns in order of importance
  • Numbers right-aligned and formatted, header too
  • Row actions: inline for one or two, else a ⋯ menu with an aria-label
  • Header stays in view on long tables; empty and loading states in place
  • Checked at 390 px: fewer columns, or sideways scroll inside the table only
