Which one

By how many options there are and whether people already know the answer. A select never takes more than one value. Native Select first; the custom Select only for custom styling or richer options. The customizable <select> (appearance: base-select) is only an extra: not in every browser yet, it falls back to a classic select.

Before you ship

In code: Native Select is <select class="select"> with <optgroup label> (data-size="sm" for 32 px). Select is Basecoat's <div class="select">: a <button aria-haspopup="listbox">, a [data-popover] with role="listbox" of role="option" data-value, a hidden input (needs select.min.js). Combobox is <div class="combobox"> with <input role="combobox"> and a listbox with data-empty (needs combobox.min.js; APG Combobox pattern).

  • 5 or fewer options are radios; a long list is a Combobox; otherwise a Native Select unless custom styling is needed
  • Options in a logical order, long lists grouped
  • Questions start with no value; settings with the usual one
  • A visible label; errors set aria-invalid
  • Unavailable options disabled, not hidden
