Tooltip

A tooltip is a short text label shown when a control is hovered or focused. Anything people click into belongs in a popover; a preview of a link is a hover card; what people need to finish the task stays on the screen.

Before you ship

In code: role="tooltip", linked with aria-describedby; it never takes focus. Basecoat: data-tooltip="Delete row" (+ data-side, data-align), CSS-only and text-only, so Esc needs a few lines of script. Popover API: a popover is popovertarget + popover (click outside and Esc close it); a tooltip can be popover="hint" shown on mouseover/focus. Newly available (Baseline 2025): check Object.hasOwn(HTMLElement.prototype, "popover") and keep a fallback; hint acts as manual where unsupported. Position with a few lines of JS; CSS anchor positioning (Baseline 2026) only as an extra.

  • Nothing needed to finish the task is only in a tooltip
  • Plain text only; anything clickable is in a popover
  • Shows on hover and keyboard focus; Esc hides it; the pointer can move onto it
  • Icon-only buttons have an aria-label and a tooltip; comparable controls all have one
