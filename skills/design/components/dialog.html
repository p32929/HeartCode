Dialog

A dialog sits over the page and blocks it: for a short task that must be done now. An alert dialog asks for a decision and closes only by answering. Anything longer, optional or not urgent goes in a sheet, a page or inline.

Worth the interruption

A short task or a critical decision. Never promos.

Always a title

The main button repeats its verb.

Confirm only what's serious

Hard to undo. Routine actions get Undo.

Name the thing and the result

"Delete file" / Cancel, not Yes / No.

Before you ship

In code: a native <dialog> opened with showModal(), not a div and a script (on top of everything, the page behind inert, focus moves in and stays inside, Esc closes, focus returns to the trigger); ::backdrop dims the page; autofocus on the element to use first (Cancel in a confirmation); open and close animated with @starting-style + allow-discrete (Tailwind starting:, Basecoat already does it), an extra (Baseline 2024) it must work without; aria-labelledby → the title, aria-describedby → the description; a confirmation gets role="alertdialog". Basecoat: <dialog class="dialog"> or class="alert-dialog" › <div> › header (h2, p), section, footer; a Dialog adds a ghost ✕ button and a backdrop-click close, an Alert Dialog neither.

  • A dialog is really needed (not a sheet, page or inline message), and none opens another
  • A title, and the primary button repeats its verb
  • Confirmations only for hard-to-undo actions, naming the thing; outcome buttons, focus on Cancel
  • A native <dialog> with showModal(): Esc closes it, focus returns to the trigger; fits a 390 px screen
