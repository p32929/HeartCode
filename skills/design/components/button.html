Button

A button does something: saves, sends, deletes, opens. If it only goes to another page, it's a link, even when it looks like a button.

One primary per view

Everything else is quieter.

Say what happens

"Save changes", not "OK".

Red only when it's serious

Hard to undo; never the default.

States visible

Hover, focus, loading. Avoid disabled.

Which kind

Loudness follows importance. Too many actions? The rare ones go in a ⋯ menu.

Primary

The one main action of a page, dialog or card.

Secondary · Outline

The other actions beside it.

Ghost

Repeated, low-priority: toolbars, table rows.

Destructive

Hard to undo. The final confirmation, never the default.

Link
Forgot it?

An action inside a sentence.

Do

One primary: the eye goes straight to "Publish".

Don't

Three primaries: nothing stands out.

Label

A verb and its object, sentence case, 1–3 words, true to what happens.

Do

Says exactly what happens.

Don't

Says nothing about the result.

Do · a confirmation
Delete this project?

Its 14 files go too.

Repeats the question's verb, not "Yes".

Icon

Only when it makes the action quicker to recognize; never decoration.

A well-known action.

After: where it goes

Direction or a menu.

Icon-only

Universal actions in tight spaces, with an aria-label and a tooltip (hover them).

Size

Default almost everywhere; 8 px between buttons; 44 px tap area on touch.

Placement

Where the reading ends, in the same order everywhere.

Do · a form

Under the last field, left-aligned with it.

Do · a dialog
Rename file

Bottom right, the primary last.

States

Hover, focus and loading are visible. Hover and Tab to these.

Hover · focus

Never remove the focus ring: keyboard users need it.

Loading

Same button, same width; extra clicks ignored.

Do · instead of disabled

Choose a plan first.

Enabled, and it says what's missing (click it). A disabled button says nothing.

Before you ship

In code: <button type="button">, type="submit" for a form's one submit; never a clickable div; going to a URL is <a href>.

  • One primary per view
  • Every label is a verb and its object
  • Destructive only for hard-to-undo actions, never the default
  • Icon-only buttons have an aria-label
  • Focus ring and loading state visible
