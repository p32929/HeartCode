Typography

The text itself: headings, paragraphs, muted text, lists and inline code. A component's own text (a button's label, a field's help) follows that component's guide.

Headings follow the structure

h1, h2, h3; no skipped levels.

Sentence case

"Billing details", not "Billing Details".

Muted is secondary

Descriptions, help, metadata; never the main content.

Numbers when order matters

Bullets otherwise.

Before you ship

In code: real elements, h1–h6, p, ul/ol with li, code; never a styled div for a heading or a list. Basecoat has no typography classes: use the Tailwind classes above.

  • Heading levels in order, none skipped
  • Every heading in sentence case
  • Muted text only for secondary information
  • Ordered steps are a numbered list; other lists bulleted, with a lead-in
  • Code, commands and file names in <code>
